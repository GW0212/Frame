# FRAME! v20 — 영화 분류형 게임

## 메인 메뉴
- 종합: 한국 영화 + 외국 영화 전체 문제
- 한국 영화: 한국 제작 영화 폴더만 출제
- 외국 영화: 해외 제작 영화 폴더만 출제

각 버튼을 클릭하면 난이도 선택 화면으로 이동합니다. `전체(n개)`는 선택한 범주와 난이도의 실제 장면 수를 표시합니다. 부족한 문제 수는 자동으로 비활성화됩니다.

## 영화 폴더 구조
```
movies/
  한국 영화/
    기생충/
      포스터.jpg
      쉬움/장면.jpg
      중간/장면.jpg
  외국 영화/
    인터스텔라/
      포스터.jpg
      쉬움/장면.jpg
  manifest.json
```

새 영화 추가 시 제작 국가에 맞는 폴더에 넣어 주세요. `tools/build_manifest.py`가 한국/외국 영화의 경로와 분류를 자동 생성합니다. GitHub Actions로 배포하면 manifest를 다시 생성하므로 별도 PC 실행은 필요하지 않습니다.

**주의:** GitHub 저장소에서 기존 `movies/기생충`처럼 최상위에 있던 영화 폴더는 신규 분류 경로로 이동했습니다. 업데이트할 때 이전 폴더를 삭제해야 같은 영화 자료가 저장소에 중복으로 남지 않습니다.

영화 국적은 제작 국가를 기준으로 분류했습니다. 예를 들어 `케이팝 데몬 헌터스`는 미국 제작 애니메이션으로 외국 영화에 포함했습니다.

## GitHub Pages
1. ZIP을 풀고 파일/폴더 전부를 GitHub 저장소 최상위에 업로드합니다.
2. `.github/workflows/deploy.yml` 등 숨김 폴더 포함 여부를 확인합니다.
3. Settings → Pages → GitHub Actions를 선택합니다.
4. 배포 완료 후 웹사이트 접속해 확인합니다.

로컬 `index.html` 더블클릭 환경에서는 브라우저 보안 정책에 의해 `movies/manifest.json` fetch가 차단될 수 있습니다. Live Server 등 로컬 웹서버에서 테스트하세요.
