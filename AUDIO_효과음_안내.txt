FRAME! v14 — 통합 사운드 구성

[사용자 제공 원본 MP3, 내용 변경 없이 포함]
assets/audio/next_scene.mp3 = 다음 장면으로 넘어갈 때 (전환 시마다 재생)
assets/audio/guess_timer.mp3 = 5초 안에 정답 맞춰야 할 때 (추리 시작에 한 번만 재생)
assets/audio/answer_reveal.mp3 = 5초 카운트 이후 정답 공개 할 때 (정답 공개에 한 번만 재생)

[추가 제작 효과음 — 부드러운 우드 클릭 + 금속 벨]
ui_click.wav = 일반 버튼 클릭
ui_select.wav = 난이도 및 선택 항목
ui_open.wav = 팝업 열기
ui_back.wav = 팝업 닫기
game_start.wav = 게임 시작
scene_show.wav = 영화 장면 표시
pause.wav = 일시정지
resume.wav = 이어하기
game_finish.wav = 모든 문제 종료
notice.wav = 링크 미등록 알림

[배경음악]
bgm_menu.mp3 = 32초 길이의 루프형 오리지널 잔잔한 펠트 피아노·벨 BGM
메인 화면 / 게임 설정 / 게임 종료 화면에서 작은 볼륨으로 재생
실제 장면 감상 및 5초 추리 / 정답 공개 중에는 BGM 일시 중지

[재생 규칙]
- 스피커 버튼으로 BGM과 모든 효과음 한번에 ON/OFF
- 사용자가 처음 클릭하거나 키보드를 눌러야 BGM 재생 가능(브라우저 자동재생 정책)
- 일시정지 중에는 5초 타이머 MP3와 화면 카운트다운 함께 중단, 이어하기 시 재개
- 정답 3초가 끝나 다음 장면으로 넘어가면 정답 공개 음원도 중단해 겹침 방지
- 5초 카운트다운 동안 기존 별도 초 단위 효과음은 제거(업로드한 타이머 음원과 중복 방지)
- 효과음과 음악은 로컬 파일이며 GitHub Pages에서 API 없이 동작
